**ZIP extraction:** the v1.20 package was produced on Windows and may use backslashes in ZIP member names. Non-Windows tools should normalize Windows-style separators and verify the directory layout. The root [SHA256SUMS.txt](SHA256SUMS.txt) lists individual files *inside* the tagged ZIP. See the [integrity checker](scripts/verify_distribution.py).
