# Contributing to True Trading Cost Planner

We welcome reproducible bug reports, documentation improvements and verified calculations.

1. Search [existing Issues](https://github.com/fxliner/true-trading-cost-planner-mt4-mt5/issues) before opening a new one.
2. Describe MT4/MT5 version and build, symbol, account currency, lot constraints, assumptions and expected arithmetic.
3. If changing calculations, demonstrate that bid/ask spread is not charged twice and costs/volume rounding remain consistent.
4. Provide test scenarios rather than unverified claims about broker fees, latency or live execution.
5. Preserve the MIT License and source attribution.

Do not share passwords, account numbers, private orders or proprietary broker credentials.

Project education hub: [FOREXREVIEW.TOP](https://forexreview.top/).
