# Security policy

## Supported version

The current free MT4/MT5 distribution is v1.20. Older builds may not receive fixes.

## Reporting sensitive findings

Do not publish credentials, account numbers, personal data, broker trade logs, tokens or exploitable security details in public GitHub Issues.

Use GitHub's private vulnerability reporting facility if the repository offers **Report a vulnerability** under Security. Otherwise open a minimal non-sensitive issue requesting a private contact channel, without posting vulnerability details.

This indicator does not place orders. Download source and binaries only from the project's documented public GitHub and MQL5 pages; always check the version and files before installing.
